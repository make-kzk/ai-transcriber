# AI Transcriber

Расшифровка встреч с разделением по говорящим, сверка нескольких систем
распознавания между собой и разбор речи по объективным метрикам.

Утилита выросла из простого обёртки над Whisper. Оказалось, что одна
система распознавания на русской речи с английскими терминами ошибается
предсказуемо и незаметно — теряет отрицания и перевирает аббревиатуры,
оставляя гладкий и убедительный текст. Поэтому здесь несколько систем,
сверка между ними и пометка мест, где они не сошлись.

---

## Что делает

- **Распознаёт** запись несколькими системами независимо: Whisper на
  облачной видеокарте, Gemini, ElevenLabs, Nexara, Deepgram.
- **Сводит** результаты и помечает расхождения, отдельно выделяя те, что
  меняют смысл, — потерянное отрицание, изменённое число.
- **Разбирает речь** по измеримым величинам: баланс времени, темп, паузы,
  запинки, слова-паразиты, высота голоса, громкость.
- **Готовит разбор для HR** по настраиваемому брифу — это единственный
  шаг, где участвует языковая модель.

## Установка

```bash
git clone git@github.com:make-kzk/ai-transcriber.git ~/ai-transcriber
cd ~/ai-transcriber && ./install.sh
```

Установщик создаёт окружение Python, ставит зависимости, кладёт симлинки
в `~/.local/bin` и собирает приложение `AI Transcriber.app` в
`/Applications` и на Рабочий стол.

Нужен [аккаунт Modal](https://modal.com) для Whisper: `modal setup`.
Остальные системы подключаются ключами и все необязательны.

### Ключи

Каждая система нужна только если вы её отмечаете. Ключи — в
`~/.bash_profile`, приложение подхватывает их само.

| Переменная | Для чего | Где взять |
|---|---|---|
| `GEMINI_API_KEY` | Gemini 3.5 Transcribe и разбор по брифу | [Google AI Studio](https://aistudio.google.com) |
| `ELEVENLABS_API_KEY` | ElevenLabs Scribe | [elevenlabs.io](https://elevenlabs.io) |
| `NEXARA_API_KEY` | Nexara | [nexara.ru](https://nexara.ru) |
| `DEEPGRAM_API_KEY` | Deepgram Nova-3 | [deepgram.com](https://deepgram.com) |

Для Whisper нужен доступ к моделям диаризации — примите условия на
[speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)
и [segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0),
токен положите в секрет Modal с именем `huggingface-secret`.

## Как пользоваться

### Приложение

Две вкладки.

**Транскрибация** — выбрать файл, язык, число говорящих и отметить
системы. Запуск уходит в Терминал: там вывод живой, потому что `modal`
пишет пачками, когда пишет не в терминал. Полный вывод сохраняется в
`~/ai-transcriber-logs/` — логи Modal живут сутки, и разбирать вчерашнее
падение иначе будет не по чему.

**Анализ речи** — пороги пауз, состав отчёта, список слов-паразитов и
бриф для разбора. Настройки лежат в
`~/.config/ai-transcriber/speech_analysis.json`.

### Командная строка

```bash
# Один Whisper, быстро
transcribe запись.m4a --speakers 2

# Несколько систем со сверкой
python run_pipeline.py запись.m4a --systems gemini whisper-v3 --speakers 2

# Посмотреть план без запуска и без расходов
python run_pipeline.py запись.m4a --systems gemini whisper-v3 --dry-run

# Сверить две готовых расшифровки
python compare_transcripts.py основа.txt сверка.txt

# Метрики речи, с акустикой
python analyze_speech.py расшифровка.txt --audio запись.m4a --names "Имя,Имя"
```

## Системы распознавания

Проверены на реальном деловом созвоне: 35 минут русской речи, плотно
насыщенной английскими терминами.

| Система | Цена за час | Диаризация | Особенность |
|---|---|---|---|
| Whisper large-v3 | $0.058 | pyannote | в пределах бесплатных $30 Modal |
| Whisper large-v3-turbo | $0.058 | pyannote | быстрее, точность ниже |
| Whisper large-v2 | $0.058 | pyannote | прежняя версия |
| Gemini 3.5 Transcribe | см. Spend | своя | подсказка словаря до 1000 фраз |
| ElevenLabs Scribe | $0.22 | своя | лучший результат в проверке |
| Nexara | 360 ₽/1000 мин | своя | российский сервис |
| Deepgram Nova-3 | $0.31 | своя | режим multi, $200 при старте |

### Что показала проверка

**ElevenLabs оказался заметно точнее на этом материале.** Он единственный
верно распознал аббревиатуры C-уровня и единственный не потерял отрицание
в ключевой фразе:

| Фрагмент | Whisper v3 | Nexara | Deepgram | ElevenLabs |
|---|---|---|---|---|
| финансовый директор | «СПО» | «СИПО» | «CFIO» | **«CFO»** |
| кейс с C-level | «Семео» | «Симео» | «Симео» | **«CMO»** |
| ключевая фраза | «**они все** HR-идиоты» | «они все HR и идиоты» | «они все HR-ы-идеты» | **«не все эйчары идиоты»** |

Последняя строка — причина, по которой в проекте появилась сверка. Смысл
переворачивается, а текст выглядит безупречно.

**Ошибки систем коррелируют.** Расхождение по словам между парами:

```
Whisper ↔ Nexara      12,5%     ← ближе всего
Whisper ↔ Deepgram    13,4%
Nexara  ↔ Deepgram    15,3%
Whisper ↔ ElevenLabs  16,6%     ← дальше всего
```

Whisper, Nexara и Deepgram ошибаются похоже — и там, где они ошибаются
вместе, сверка между ними слепа. Поэтому сверять стоит с системой другой
родословной.

## Сверка

`compare_transcripts.py` берёт одну расшифровку за основу, помечает в ней
несогласия со второй и выносит критичные в шапку с таймкодами.

Расхождений много — около 6% слов между двумя версиями Whisper и до 16%
между разными системами, — но подавляющее большинство это пунктуация,
слова-паразиты и запинки. Читать их бессмысленно, поэтому они делятся на
три уровня:

- **критично** — потерянное отрицание, изменённое число;
- **разночтение** — другое содержательное слово;
- **шум** — пунктуация, регистр, паразиты; не показывается.

Правила подбирались по фактам. Первый прогон дал семь «критичных», из них
настоящих было два: «нет» против «нету» и «не знаю» как оборот-паразит
отрицаниями не считаются, «3-5» и «три, пять» — одно число, а пропавший
длинный фрагмент чаще уезжает в соседнюю реплику, чем теряется.

Внешние системы режут речь по-своему, поэтому их слова раскладываются по
репликам выбранной модели Whisper — сравнивается речь из одних и тех же
отрезков записи. Слова, попавшие туда, где у эталона реплики нет,
считаются и указываются отдельно.

## Анализ речи

Отдельный пакет `speech_analysis/`, не зависящий от системы транскрибации:
он знает только формат расшифровки и применим к файлу любого
происхождения.

**Считается по расшифровке:** время в эфире и его доля, число и длина
реплик, темп речи и его разброс, слова-паразиты, вопросы, перебивания,
паузы между репликами.

**По пословным таймкодам:** паузы внутри реплики, запинки трёх видов —
обрыв слова, заполненная пауза, повтор слова.

**По звуку** (Praat через `parselmouth`): высота голоса и её разброс в
полутонах, громкость и её разброс, темп артикуляции. Это и есть честная
замена «энергичности» — три измеримых числа вместо ярлыка.

Оценок вроде «уверенно», «нервозно» или «радость» здесь нет намеренно: по
тексту и таймкодам они не выводятся, но выглядят убедительно и потому
вводят в заблуждение.

### Ограничения, о которых сказано в самом отчёте

- Время реплик округлено до секунды — темп на коротких не считается.
- **Запинки видны только там, где система их сохраняет.** Whisper
  причёсывает речь, ElevenLabs и Deepgram оставляют. Сравнивать их счёт
  между системами бессмысленно.
- Разброс тона дан в полутонах: мужской и женский голос в герцах
  несравнимы.
- Слоги считаются по гласным — приближение, достаточное для темпа.

## Разбор по брифу

Единственное место, где участвует языковая модель. На вкладке анализа
выбирается сценарий (собеседование, оценка подрядчика, внутренняя
встреча), кто есть кто, пункты разбора и дополнительный контекст.
Значения подставляются из сценария и переписываются вручную.

Кнопка **«Показать бриф»** показывает ровно то, что уйдёт в модель,
вместе с оценкой стоимости — бесплатно. Перед отправкой спрашивается
подтверждение с суммой.

Запись можно отправить вместе с текстом: Gemini принимает аудио напрямую
и слышит интонацию сам. Аудио тарифицируется как 32 токена в секунду, и
разбор с записью выходит около 8 центов на 36 минут.

В системной части запретов больше, чем указаний: не оценивать личные
качества по тексту, не выносить вердикт о пригодности человека, не
трактовать темп и паузы как нервозность. Речевые метрики передаются как
фон, а не доказательство.

## Структура

```
transcribe_modal.py       Whisper на видеокарте Modal
transcribe_gemini.py      Gemini 3.5 Transcribe
transcribe_elevenlabs.py  ElevenLabs Scribe
transcribe_nexara.py      Nexara
transcribe_deepgram.py    Deepgram Nova-3
transcript_utils.py       общее для адаптеров: формат, раскладка, сверка

run_pipeline.py           цепочка: несколько систем и сведение
compare_transcripts.py    сведение двух расшифровок с пометками
analyze_speech.py         обёртка для командной строки

speech_analysis/          самостоятельный модуль разбора речи
  config.py               настройки
  metrics.py              вычисления
  acoustics.py            тон, громкость, темп артикуляции
  brief.py                сборка брифа — читается и правится глазами
  llm.py                  отправка в Gemini — единственное, что тратит деньги
  report.py               форматирование

transcribe_gui.py         приложение
transcribe                команда для терминала
install.sh                установка и сборка .app
```

## Что проверено, а что нет

**Проверено на данных:** сравнение пяти систем распознавания на реальной
записи; правила разметки расхождений; акустика (206 Гц у женского голоса,
115 Гц у мужского — измеряется именно то, что нужно).

**Опровергнуто проверкой:** оценки достоверности выравнивания wav2vec2 не
годятся как детектор ошибок — они меряют длину слова, а не правильность
(1–2 буквы дают 0,72, семь-девять букв 0,87), и слепы к пропущенным
словам: оценивать нечего, если слова нет. Точность около 6%.

**Не проверено:** качество Turbo на русском; разбор по брифу на реальном
материале; работа приложения из бандла с файлами в защищённых папках
macOS — при отказе доступа держите записи в незащищённой папке вроде
`~/ai-audio`.

# 🎙️ AI Transcriber (WhisperX + Pyannote Diarization on Serverless GPU)

Автономное настольное приложение и CLI-утилита для macOS (Intel и Apple Silicon) для автоматической транскрибации речи с разделением по спикерам (ролям).

Вычисления происходят в облаке на серверных видеокартах **Nvidia A10G (24 GB VRAM)** через платформу **Modal.com**, что решает проблему медленной или невозможной локальной диаризации на процессорах Intel.

---

## ⚡️ Ключевые возможности

- **Высокая точность:** Модель OpenAI Whisper `large-v2` с поддержкой русской и мультиязычной речи.
- **Разделение по ролям (Diarization):** Нейросеть `Pyannote.audio` автоматически определяет голоса говорящих (`SPEAKER_00`, `SPEAKER_01` и т.д.) или принимает фиксированное количество участников.
- **Сверхточный тайминг:** Слоговое и пословное выравнивание таймкодов (forced alignment) через `wav2vec2`.
- **Серверлесс-архитектура:** Видеокарта поднимается только на время расшифровки файла (~1-2 минуты на 35 минут аудио) и моментально выключается.
- **Бесплатная квота:** Modal предоставляет **$30 ежемесячно** каждому аккаунту (этого хватает на сотни часов транскрибаций в месяц бесплатно).
- **Нативное приложение macOS:** Графический интерфейс на рабочем столе (`AI Transcriber.app`) с выбором файлов, настройками, логами в реальном времени и системными уведомлениями.
- **CLI для терминала:** Быстрая команда `transcribe audio.m4a --speakers 2`.

## 🚀 Пошаговая инструкция по установке с нуля

### Шаг 1. Регистрация на Modal.com
1. Перейдите на [modal.com](https://modal.com) и зарегистрируйтесь через GitHub или Google.
2. В разделе **Settings -> Tokens** ([modal.com/settings/tokens](https://modal.com/settings/tokens)) нажмите **«New Token»**.
3. Скопируйте команду настройки токена:
   ```bash
   modal token set --token-id ak-... --token-secret as-...
   ```

### Шаг 2. Получение токена Hugging Face (для модели диаризации)
1. Зарегистрируйтесь на [huggingface.co](https://huggingface.co).
2. Примите условия использования моделей Pyannote (нажмите кнопку **«Agree and access repository»** на каждой странице):
   - [pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)
   - [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0)
3. Создайте токен доступа с правами `Read` в [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
4. Зарегистрируйте секрет в Modal:
   ```bash
   modal secret create huggingface-secret HF_TOKEN=ваш_токен_hf_...
   ```

### Шаг 3. Установка на Mac
Клонируйте репозиторий и запустите скрипт быстрой установки:
```bash
git clone https://github.com/make-kzk/ai-transcriber.git
cd ai-transcriber
chmod +x install.sh
./install.sh
```

Скрипт автоматически:
1. Создаст изолированное виртуальное окружение Python.
2. Установит клиент `modal`.
3. Соберет нативное приложение `AI Transcriber.app` и поместит его в `/Applications` и на Рабочий стол.
4. Добавит команду `transcribe` в ваш терминал (`~/.local/bin/transcribe`).

## 💻 Использование

### Вариант 1. Через графическое приложение
1. Запустите **AI Transcriber** с Рабочего стола или из папки Программы.
2. Нажмите **«Выбрать файл...»** и укажите любое аудио или видео (`.m4a`, `.mp3`, `.wav`, `.mp4`, `.mov` и т.д.).
3. Укажите число спикеров (например, `2` или `Автоопределение`).
4. Нажмите **«🚀 Начать транскрибацию»**.
5. По завершении прозвучит сигнал, и вы сможете сразу открыть текстовый файл или показать его в Finder.

### Вариант 2. Через Терминал (CLI)
```bash
# Базовый запуск
transcribe meeting.m4a

# С указанием количества спикеров
transcribe meeting.m4a --speakers 2

# С указанием языка
transcribe interview.mp3 --language ru --speakers 3
```

Файл с результатом `..._транскрибация.txt` сохраняется в той же папке рядом с исходным медиафайлом.

## 🔒 Конфиденциальность и безопасность
- В репозитории **нет API-ключей и токенов**.
- Ключ Hugging Face хранится в зашифрованном хранилище Modal (`modal.Secret`).
- Токены Modal хранятся в защищенном локальном файле конфигурации пользователя `~/.modal.toml`.
